🚀 TrustBuilder MFA Lib
=======================

📋 Overview
-----------

The MFA Lib SDK is made by TrustBuilder to add MFA features into your iOS application for your Safe-T organization.

📦 Installation
---------------

### Swift Package Manager

Install the TrustBuilder MFA Lib SDK with the [Swift Package Manager](https://docs.swift.org/swiftpm/documentation/packagemanagerdocs/) by adding the URL:

```
https://github.com/trustbuilder/trustbuilder-mfa-lib
```

⚡ Usage
-------

Import the appropriate component in your Swift file to use the SDK:

```
import TrustBuilderMfaLibSwift
```

Refer to our [documentation](https://docs.trustbuilder.com/safe-t/mfa-sdk-mobile-ios) to find out how to use this SDK
